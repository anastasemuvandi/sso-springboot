# Console — platform area (console-web, Phase A)

React 18 + TS strict + Vite SPA in `console-web/`, behind the BFF. Conventions,
commands and "how to add a page" are in `console-web/README.md`.

## Code locations

| What | Where |
|---|---|
| Typed API client (openapi-fetch over generated `schema.d.ts`), `ApiError`, CSRF, downloads | `console-web/src/api/` |
| Session (`GET /bff/session`), 401 → re-check → `/bff/login?returnTo=` | `console-web/src/auth/` |
| Routes + cosmetic guards (loaders), providers | `console-web/src/app/` |
| Shell (sidebar, top bar, language switcher en/rw, theme, sign-out), shadcn/ui, common widgets | `console-web/src/components/` |
| Pages per feature | `console-web/src/features/<feature>/pages/` |
| Pure state modules + unit tests | `console-web/src/features/**/state/` |
| i18n | `console-web/src/i18n/{en,rw}.json` |
| Playwright gate + stub BFF/wrapper | `console-web/e2e/`, `console-web/playwright.config.ts` |
| Contract used for types | `console-web/openapi.reference.json` (copy of the reference); `npm run gen:api` switches to `sso-wrapper/openapi.json` once it exists |

## Pages (platform area)

`/dashboard`, `/clients`, `/clients/new`, `/clients/:id`, `/clients/join-keys`,
`/users`, `/users/new`, `/users/:id`, `/agencies`, `/agencies/new`,
`/agencies/:id`, `/roles`, `/employees`, `/audit`, `/system-audit`, `/settings`,
`/api-explorer` (Swagger UI over `/api/v3/api-docs`, lazy). Plus `/no-access`,
404 and a route error boundary. The institution area (`/institution/**`) is built on the same shell — see
`docs/implemented/console-institution.md`.

## Endpoints called

BFF: `GET /bff/session`, `GET /bff/login?returnTo=`, `POST /bff/logout` (form
post with `_csrf`). Wrapper (through `/api`): see each feature's `api.ts`; the
paths, methods and JSON names are the reference contract's.

## Tests

- Vitest unit: `mfaStatus` (mirrors `mfa-policy` MfaPolicy: mode/legacy fallback/
  client attribute), `clientScopeForm` (scope form + 409 confirm reducer),
  `clientAccessState` (granted/open/revoked/not_granted/exempt/unknown),
  dashboard `attention`, API client (envelope mapping, XSRF, 401 redirect),
  route guards, i18n en/rw key parity.
- RTL + MSW component tests: dashboard (section unavailable vs zero, refresh
  `?refresh=true`), client scope 409 confirm, user app-access grant/revoke/restore,
  plus feature tests listed in the feature folders.
- Playwright `e2e/auth-guard.spec.ts` against `vite preview` + `e2e/stub-server.mjs`:
  unauthenticated → `/bff/login`; 401 mid-session after a failed BFF refresh →
  re-login → back; platform admin → `/dashboard`; institution admin →
  `/institution`; no admin role → `/no-access`.

## Contract (wrapper openapi.json is the source of truth)

`npm run gen:api` generates from `sso-wrapper/openapi.json` (regenerated by the
wrapper's `OpenApiContractTest -Dopenapi.update=true`). The console was audited
against it and against the Java controllers/services for untyped (Map)
responses; see "Contract alignment" in `console-institution.md` for the full
mismatch list and what changed. Agreed shapes the console relies on: scope 409
`confirm_required` details `removed_institutions`/`access_at_risk`/
`current_scope`/`requested_scope`; join-column 409 `active_sessions`/
`assigned_users`; per-user access `{action: grant|revoke|restore,
expected_state}` with 409 `state_changed|not_applicable|denied_by_group` +
`details.current_state`; client access `denied_users:[{id,username}]`;
exemptions `{exemptions:[…]}`; validation 422 `validation_error` with
`details.fields[{field,message}]`; BFF `GET /bff/session`, `/bff/login?returnTo=`,
`POST /bff/logout` (`_csrf`), springdoc at `/api/v3/api-docs`.
